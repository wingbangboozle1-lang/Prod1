How links are marked

Every outbound affiliate/product link carries rel="sponsored" so search engines and readers can tell it is a paid placement. This satisfies Google’s guidance on qualifying outbound links (S-05, implemented 2026-11-16) without breaking the required disclosure (S-05).

Policy basis

  • Amazon Associates Program Policies (S02).
  • FTC — Disclosures 101 for social media influencers (S-07).

Disclosures and Amazon API policy checks are part of the publishing workflow: placement of the Associates statement and endorsement context are reviewed against the Operating Agreement and FTC guidance before any page is published. The disclosure strip is rendered server-side (in the HTML) on every page so it cannot be stripped by a client-side script failure.
