How each outbound link is marked

  • URL format: https://www.amazon.com/dp/ASIN?tag=shopnow047c-20 (official listing URL + tracking ID).
  • Attributes: rel="sponsored nofollow noopener", target="_blank", visible "sponsored" label and "Opens amazon.com" text so destination is never obscured.
  • Short links are recorded in the verification register as submitted links with observed redirect targets in a separate field. They are not used as outbound buttons.
