Findings

  1. The five submitted links point to five different listings: three air fryers and two thermometers. The short-link codes are not ASINs, so each intended ASIN is read from the resolved URL (P-03).
  2. No resolved link carries the tag. The site therefore links to tagged listing URLs in the format Associates describes, and keeps the observed targets in their own column (P-02, P-04).
  3. The 8 Qt link opens a variation page. The resolved URL includes th=1; the other size options were not checked (P-08).
  4. Units in titles differ. Two titles use Quart, one uses QT. Units are not converted (P-07).
  5. Price and rating analysis cannot appear on a static site under the current policy. The owner must choose between API access and price-free listings (P-05).
