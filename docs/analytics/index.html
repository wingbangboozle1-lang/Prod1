Analytics and measurement

Tracker status: off. No endpoint is hosted. GitHub Pages serves static files only, so the collector in endpoint/ must run on a server the owner controls (F-07).

The brief refers to "the five defined events" but does not list them. These five are a proposal (F-06).

Privacy design

  • No cookies, no localStorage, no fingerprinting.
  • The tracker sends the event name, the path without query string, and a product ID for outbound clicks.
  • The collector stores daily counts only: no IP address, no user agent.
  • Nothing is sent until an endpoint URL is set in the page's analytics-endpoint meta tag.

What is needed before this is on

  1. Owner approves the event list (Q-06).
  2. Owner chooses a hosting option (SG-01).
  3. A privacy notice and consent approach are written (Q-05).
