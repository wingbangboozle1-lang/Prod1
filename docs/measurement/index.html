Measurement

Clicks on Amazon links are recorded as named events. No cookies, no local storage, no fingerprinting. Nothing leaves the browser unless an endpoint is set in the page head.

Endpoint

GitHub Pages is static hosting and cannot run a self-hosted analytics endpoint. To turn events on, set the analytics-endpoint meta tag on each page to an HTTPS URL you control (see Suggestion S-05). Until then, the counter records to memory only.
