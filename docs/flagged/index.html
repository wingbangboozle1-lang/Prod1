FL-01 High Irregularity

Submitted link codes are not the ASINs the pages resolve to

Each submitted link.amazon URL carries a 9-character code after the slash (e.g. B04G1MEwY). Each one resolved to a different Amazon listing (ASINs B0CDY277D3, B09B7SB46R, B08DKYBTPH, B0DHZTCNR5, B0DZFD6R9Z). The codes in the submitted links were therefore NOT used as the intended ASIN. The observed ASIN is stored in its own field.

Checked
fetch_page on all five submitted links (final URL and page title read).
Not checked
Whether the link.amazon short-link service maps these codes to the listed ASIN by design.
